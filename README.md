# Hegemony 四人連線遊戲

以基本版規則 v1.2 為基礎，製作四位真人分別扮演勞工、中產、資本家、國家的連線遊戲。

新房間使用基本版內容。四個角色各自從 40 張行動牌洗牌抽牌。遊戲從原版牌庫揭示企業、國家事件、出口、商業交易與政治綱領，並抽移民牌。每輪有 20 個行動回合，接著結算企業生產、薪資、食物需求、IMF、稅款、選舉、事件懲罰與輪末得分。第五輪後顯示終局排名。

## 啟動試玩

需要 Node.js 24 以上。從專案根目錄執行下列指令，再開啟 `http://127.0.0.1:4173`。

```powershell
npm start
```

建立房間並將邀請連結交給另外三位玩家。四席入座後由房主開始。同一台電腦測試時，每個角色使用獨立分頁或瀏覽器設定檔。重新整理原分頁可回到自己的席位。對局及待決投票存於 `.runtime/`，重啟伺服器會讀取原房間。

使用 `npm start` 啟動後，本機 `/quick` 可重載伺服器，重載後使用同一個網址及存檔目錄，已送出的進度與席位都會保留。快速開桌也可用房主席位刪除目前房間，確認後會移除對局存檔。

遊戲畫面有中央 SVG 圖板與四張可切換的階級圖板。點選手牌後，在行動區確認卡牌效果或基本行動。拖放工人、市場企業或資源會預填對應行動，也可先點選物件，再選標亮的放置區。

工人可拖到中央圖板上的企業卡或指定工位，市場企業可拖到中央圖板的私營部門。主要行動和免費行動各自開啟確認視窗，列出本次影響，確認後立即執行。兩者可任選先後，確認主要行動後仍須手動結束回合。食物結算時的借貸會等待該席確認或取消，重整頁面可繼續處理。

同一區域網路內使用不同裝置時，在 PowerShell 設定 `$env:HOST = '0.0.0.0'` 再執行 `npm start`。各玩家用主機的區網 IP 及 `4173` 連線。這個設定適用於受信任的區域網路。

執行 `npm test` 可驗證新版四席 100 次主要行動、四角色卡牌效果、事件、商業交易、企業市場、手牌隱私及終局得分，另有表決重連、食物借貸、IMF 和稅款的回歸測試。

第 20 個回合後，由中產、勞工依序確認食物需求。前四輪計分後由房主按「開始下一輪」，接著資本家和中產依序選擇要棄掉的市場企業並補牌，中產同時選擇新技術工的技能。新版內容適用於新建房間。

## 資料狀態

107 個行動牌面與 25 個事件都有引擎定義。五輪測試涵蓋代表性效果與階段轉換，逐牌裁決和罕見組合仍需驗證。事件福利的資源來源由引擎依固定順序扣除。一般的扶植新興產業事件由接收企業的玩家決定雇用，連續處理同一事件時仍由國家一併提交。公營開關企業仍採固定順序。待確認的欄位及原版開局條件見[資料缺口與裁決](docs/DATA-GAPS.md)。

原始PDF位於 `D:\download\Hegemony-English-Rulebook-v1.2.pdf`，未複製進專案。原先輸出資料保留在 `D:\codex\output\hegemony`。

## 重新產生基礎資料

使用 Python 3 執行 `python scripts/build_data.py`，輸出至 `data/hegemony-v1.2-data.json`，同時核對四類元件總數。腳本只建立已整理的基礎資料，不會下載或補入卡牌。

已有完整內容目錄，可直接讀取 JSON。需要重新產生時，先儲存 [Ludex 卡牌索引](https://www.ludex.dev/hegemony/cards/) 的 HTML，再執行 `python scripts/build_catalog.py --html <HTML 路徑>`。
