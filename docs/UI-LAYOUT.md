# 遊戲介面布局參考

參考來源：[BGA Hegemony互動教學2240](https://zh.boardgamearena.com/tutorial?game=hegemony&tutorial=2240)。觀察日期：2026-11-06。

本文件區分實際觀察與本專案建議，不複製BGA程式或素材。教學畫面是勞工對資本家的兩人局，不能作為四人設置或四人完整畫面的證據。此次可見視窗約755px寬；未驗證寬螢幕布局、觸控或各種裝置斷點。

## 實際觀察

1. 頂端玩家摘要列以角色色區隔，包含名稱、VP及角色關鍵值。勞工顯示人口、繁榮、錢與影響力；資本家顯示營收、資本、影響力與庫存。
2. 行動提示列在捲動時仍固定於頂部，顯示當前任務與「基礎行動」「自由行動」入口。
3. 輪次1–5、稅倍率以獨立追蹤列呈現，另有計算器圖示。
4. 手牌是可收合的獨立區塊，標示張數，卡牌橫排緊密呈現；卡面包含前提、效果及圖示。
5. 自己角色版圖在手牌後方：人口與工人數、金錢、資源、繁榮軌、五產業工會；另有「檢視對手版圖」入口。
6. 公共服務以醫療、教育、影響力三個計數面板呈現數量、容量及單價；國庫與國家貸款在同區旁邊。
7. 公共部門標示目前／最大企業數，企業卡橫排；私營企業按企業擁有者分組，資本家標示4/12。
8. 企業卡直接顯示技能工位、產量、機械加成與三級薪資，目前薪資有選取標記。
9. 待業勞工獨立成區，能看到各工人技能。
10. 政策1–5為五列、每列A/B/C；政策6、7在右側上下排列。現行政策填實色，其他格暗色；下方顯示三階級投票袋數量，區塊有預投票入口。
11. 對外貿易同區分成商業交易、出口、進口三欄。進口顯示總價，並拆解基價＋關稅；出口同時列出各資源交易。
12. 供應區以階級／技能分組，列出剩餘投票方塊、影響力與工人數量。
13. 頁面亦有玩家版圖側面板、資本家「玩家版圖／市場」頁籤、快速參考與棄牌區入口；此次未逐一展開驗證其交互行為。
14. 整體採深色紋理底、圓角細框、可收合標題與資源色。勞工紅、中產黃、資本家青藍；農業綠、奢侈品藍、醫療紅、教育橙、影響力紫。

## 本專案桌面版建議

以資訊分區及行動提示為主要參考。優先讓玩家在操作時同時看到自己的資源、目標與成本。

| 區域 | 內容與用途 |
| --- | --- |
| 頂列 | 輪次、階段、當前角色、剩餘回合、稅倍率、連線狀態 |
| 固定行動列 | 當前任務、基本行動、免費行動使用狀態、取消／確認 |
| 左欄 | 自己角色詳細版圖、手牌與可用資源；可收合 |
| 中央主區 | 政策、公共服務、企業、待業工人與外貿；提供區域跳轉 |
| 右欄 | 四人公開摘要、事件／政治綱領入口、對局紀錄與快速參考 |
| 詳情層 | 卡面放大、對手版圖、市場、稅額預覽與規則說明 |

各區比例與斷點需在實作時依卡面可讀性驗證，不從此次窄視窗臆測BGA桌面尺寸。避免用整張實體圖板縮放作為唯一互動介面。

## 四人版必須新增的配置

- 私營企業分資本家與中產兩區，分別標示12與8企業上限。
- 中產版圖區分「商業倉庫」與「生活資源」，避免誤用尚未轉移的資源。
- 國家版圖呈現三合法性、永久合法性標記、政治綱領、個人影響力。
- 公共媒體影響力與國家個人影響力使用清楚標籤及不同容器。
- 兩張事件及三階級福利區可直接查看待解任務、未處理懲罰與可領物品。
- 投票顯示表態、抽袋結果、秘密投入的提交狀態及共同揭露結果；不得在未揭露前顯示其他人的投入量。
- 公共與私人企業都可查看工人歸屬、技能、承諾、薪資、機械及罷工，不只用顏色表達。

## 窄螢幕配置建議

沿用此次教學可見的單欄分區方式。頂端保留精簡玩家摘要及固定行動列；以「自己／主板／政治／市場／紀錄」跳轉區域。卡片可橫向捲動或點選放大，避免文字縮到無法閱讀。

## 操作與驗收要求

- 選行動後高亮合法目標，確認前預覽成本及資源流向，拒絕時說明具體原因。
- 免費行動已用時清楚顯示，不能把多個免費行動入口誤當各可用一次。
- 即使隱藏手牌區收合，也不將其他人的手牌或秘密投入傳給客戶端。
- 用數字、文字與圖形共同區分角色、技能及狀態，不能只靠顏色。
- 在常見桌面與窄視窗驗證固定提示列不遮住目標、卡面可讀、彈層可關閉、鍵盤可操作。
- 對手版圖、卡牌詳情和規則參考只做查看，不改變行動或洩漏私人資訊。
- 教學當前顯示的庫存、公司或數值不直接覆蓋v1.2四人開局資料；新增數值另走內容核對流程。

## SVG 圖板與拖放

中央圖板參考官方 v1.2 規則書第 6 頁，四張玩家圖板參考第 7 頁。中央圖板左側有政策、外貿及兩個私營區，右側有輪次、稅倍率、投票、事件、福利、公共服務與公營區，待業工人與移民牌庫在底部。玩家圖板可從操作區切換，預設開啟自己的階級。圖板以自繪 SVG 呈現底紋、計分軌、政策格、資源槽及工人。

- 點選手牌，從主要行動選單選擇卡牌效果或一項基本行動，再確認送出。
- 選「指派工人」後才能拖放工人，最多暫放三名，再一次確認。
- 企業卡可拖到本階級的空企業格，市場更新時可拖到棄置區。
- 商業交易、出口、購買資源、媒體轉換及秘密投入也可拖放。拖放會預填表單，按下確認才送出。
- 手機與鍵盤可先選物件，再選高亮目標。長距離拖放移到畫面上下緣時會捲動。

目前可拖放的區域以遊戲引擎已有的行動為範圍。輪次、稅倍率、VP、合法性等狀態標記由伺服器狀態更新。 [官方 v1.2 規則書](https://hegemonicproject.com/wp-content/uploads/2023/04/Hegemony-English-Rulebook-v1.2.pdf)
