# 目標導向（`goal-*`）

每一輪先依盤面排出「這輪最該追求什麼」，每個回合再從所有可行行動裡選出最合乎這些目標的那一個。換一組參數就是不同個性的 AI。

| 風格 id | 名稱 | 個性 |
|---|---|---|
| `goal-balanced` | 目標・均衡 | 各項目標並重，依盤面隨時調整 |
| `goal-growth` | 目標・擴張 | 重視生產與收入，願意花錢與借貸擴大規模 |
| `goal-frugal` | 目標・保守 | 重視降低成本與滿足需求，盡量不借貸 |
| `goal-political` | 目標・政治 | 把法案與政策符合度放第一，其次才是分數 |

程式在 `packages/bots/goals/`（指標、目標、風格、候選行動）與 `packages/bots/strategies/goal.mjs`（策略本體）。

## 整體流程

```text
每一輪第一次輪到這個席位
  └─ planRound：依盤面算各目標的迫切度 → 乘上風格權重 → 排序 → 存成本輪計畫（game.botPlans）

每個回合
  ├─ mainActions：列出這個席位所有可能的主要行動（候選）
  ├─ 對每個候選：在遊戲複本上試跑 → 得到行動後的盤面
  │     指標差 = 行動後指標 − 行動前指標
  │     分數   = Σ 目標權重 × 目標對指標的影響 × 指標差 ÷ 指標尺度
  ├─ 依分數由高到低排序（同分維持候選順序，施加政治壓力排最前）
  ├─ runner 由高到低取第一個「連後續強制選擇都走得完」的命令套用
  └─ 主要行動之後：對免費行動候選做同樣的評分，分數超過 0.05 的最高者才做
```

## 1. 指標（`goals/indicators.mjs`）

指標是把「某個席位眼中的盤面」化成數字。只用該席位看得到的資訊（自己的數值與公開盤面），不看別人的手牌。

| 指標 | 意義 | 算法 |
|---|---|---|
| `vp` | 勝利分數 | 該席位目前的 VP |
| `money` | 資金 | 國家：國庫；資本家：營收＋資本；勞工與中產：現金 |
| `income` | 預期每輪收入 | 逐一檢查營運中的企業（見下）：自己領薪就加薪資；自己的企業加「產量 × 自己的售價」 |
| `production` | 生產力 | 自己企業的產量合計；勞工改算「有工作的工人數」 |
| `cost` | 預期每輪支出 | 自己企業要付的薪資合計 ＋ 5 × 貸款筆數（利息） |
| `needs` | 需求滿足 | 勞工、中產：−max(0, 人口 − 自有食物)；其他席位恆為 0 |
| `political` | 政治影響 | 符合偏好的政策數 × 3 ＋ 已提出且方向符合偏好的法案數 × 1.5 ＋ 個人影響力 × 0.5 ＋ 袋內自己的方塊 × 0.15 |
| `stock` | 庫存分 | 終局庫存計分：食物每 2 份、其他資源每 3 份得 1 分；國家另加公共影響力 ÷ 3；勞工 0 |
| `debt` | 貸款 | 已有貸款筆數 ＋ ceil(max(0, 應付薪資 − 資金) ÷ 50)（資金不夠付薪資時預期要新借的筆數） |

收入與支出的細節：

- 企業「領薪對象」：中產的企業看選配的員工工位，其他企業看第一個工位上的工人階級；被罷工且薪資未達 L3 的企業沒有薪資也不生產。
- 薪資 = 企業薪資表在目前薪資級距的金額；自己的企業要付，在別人企業工作則是收入。
- 政策偏好：勞工 A、中產 B、資本家 C（五項政策各一格）；國家看本輪政治綱領。
- 這些「預期」都是以目前盤面的靜態估計，不模擬需求或對手反應。

### 指標尺度

不同指標的單位不同，評分時先除以尺度才能相加：

| vp | money | income | production | cost | needs | political | stock | debt |
|---|---|---|---|---|---|---|---|---|
| 1 | 25 | 10 | 2 | 10 | 2 | 2 | 1 | 1 |

## 2. 目標（`goals/goals.mjs` 的 `goalDefinitions`）

每個目標是一張「指標 → 影響」的表：正數代表該指標越高越好，負數代表越低越好，絕對值是強度。

| 目標 | 影響 |
|---|---|
| 提升 VP（`vp`） | vp +1、stock +0.4、political +0.1、**debt −4**（每筆貸款終局會扣分，資本家每筆 5 分） |
| 提高生產（`production`） | production +1、income +0.3 |
| 提高收入（`income`） | income +1、money +0.4 |
| 降低成本（`cost`） | **cost −1**、debt −0.6 |
| 滿足需求（`needs`） | needs +1 |
| 推動法案（`bills`） | political +1 |

風格可以覆寫某個目標對某個指標的影響（`style.effects`），沒寫的沿用上表。

## 3. 本輪計畫（`urgencies`、`planRound`）

### 迫切度

每個目標依盤面算一個「現在有多急」的數字（0＝不急）：

| 目標 | 迫切度 |
|---|---|
| 提升 VP | 輪數 ÷ 5 × 1.5（越後面越重要） |
| 提高生產 | （有待業工人且有空缺 ? 1 : 0.2）＋（6 − 輪數）÷ 10 |
| 提高收入 | （資金 < 預期支出 × 1.5 ? 1.2 : 0.3）＋（有待業工人 ? 0.3 : 0） |
| 降低成本 | 有貸款：0.6 × 貸款筆數；否則資金 < 預期支出：1；否則 0.2 |
| 滿足需求 | 缺口 > 0：min(2.5, 缺口 ÷ 人口 × 3 ＋ 0.5)；否則 0 |
| 推動法案 | 符合偏好的政策不足 5 項：0.6 ＋（3 − 自己待決法案數）× 0.1；否則 0.1 |

### 權重與排序

```text
權重(目標) = 風格.base[目標] × (1 + 迫切度(目標) × 風格.urgency[目標])
```

`風格.urgency` 預設 1，可以放大或縮小某個目標對盤面的敏感度。把所有目標依權重由大到小排序，連同風格 id 與輪數存成 `game.botPlans[席位]`：

```json
{ "round": 3, "style": "balanced",
  "priorities": [{ "goal": "needs", "label": "滿足需求", "weight": 3.5 }, "…"],
  "last": { "kind": "main", "action": "build", "score": 1.42, "goals": [["production", 1.1], ["income", 0.3]] } }
```

計畫每輪只制定一次（輪數或風格不同才重算），存在遊戲狀態裡，所以重新整理或伺服器重啟後仍在。`last` 記錄最近一次決定的行動、分數與貢獻最大的兩個目標，方便除錯與日後顯示 AI 的想法。

## 4. 行動評分（`scoreAction`）

```text
對每個目標 g（權重 w_g，影響表 E_g）：
  貢獻_g = w_g × Σ_指標 ( E_g[指標] × Δ指標 ÷ 尺度[指標] )
分數 = Σ_g 貢獻_g
```

`Δ指標` 是行動前後指標的差，**由試跑量出來**（`ctx.preview(命令)`：複製遊戲、套用命令、取精簡視圖算指標），不需要手寫每個行動的效果表。所以新增行動只要列進候選清單就會被評估；只要指標涵蓋到它影響的面向，就會得到合理的分數。

例：資本家蓋一間企業 → `production` 增加、`money` 減少、`cost`（薪資）增加。「提高生產」目標權重高的風格會覺得值得，「降低成本」權重高的風格則不一定。

## 5. 候選行動（`goals/actions.mjs`）

候選只負責「列舉可能的命令」，是否合法由試跑決定，不合法的直接略過。

| 席位 | 主要行動候選 | 免費行動候選 |
|---|---|---|
| 勞工 | 施加政治壓力、提案、指派待業工人（整間企業一次填滿，薪資高的優先）、購買（食物、奢侈品、醫療、教育，各賣家）、罷工、示威、成立工會、出牌 | 領福利、還貸、使用奢侈品／醫療／教育、交換工人 |
| 中產 | 施加政治壓力、提案、指派、建造企業（含選配員工、三種薪資級距）、購買、出口、加班、出售企業、出牌 | 領福利、還貸、使用生活資源、交換工人、調整薪資、調整售價 |
| 資本家 | 施加政治壓力、提案、建造企業（含立即雇用）、商業交易（倉庫或自由貿易區）、出口、遊說、出售企業、出牌 | 還貸、買倉庫、調整薪資、調整售價、發放獎金 |
| 國家 | 處理事件、競選、提案、會見議員、對外出口、出牌、額外稅（共用 `engine/candidates.mjs`） | 還貸、調整薪資 |

每個階級的行動都在評估範圍內。

## 6. 選擇與驗證

1. 所有候選依分數由高到低排序（穩定排序，同分維持候選順序，「施加政治壓力」排最前面作為後備）。
2. runner 由高到低取第一個通過 `tryCommand` 的命令。`tryCommand` 除了命令本身，還要確認後續的強制選擇（抽牌選擇、政策調整、事件雇用…）走得完，所以評分時只看命令的直接效果（快），完整驗證只對被選中的前幾名做（慢）。
3. 免費行動：只取分數 > 0.05 的最高者，避免為了微小的好處亂花錢；沒有就不做。
4. 國家確實沒有任何合法行動時，runner 最後會試 `pass`（見 [AI-PLAYERS.md](../AI-PLAYERS.md)）。

## 7. 風格參數（`goals/styles.mjs`）

```js
{ id: 'frugal', name: '保守', description: '…',
  base:    { vp: 0.8, production: 0.7, income: 1, cost: 1.8, needs: 1.4, bills: 0.5 },  // 各目標基礎權重
  urgency: { cost: 1.5 },                                                               // 對盤面的敏感度（選填）
  effects: { cost: { debt: -0.2 } } }                                                    // 覆寫目標對指標的影響（選填）
```

做一個新風格：在 `goalStyles` 加一筆，`index.mjs` 會自動登錄成 `goal-<id>`，等待室下拉選單就看得到。也可以用 `createGoalStrategy(style)` 在測試裡臨時建立。

## 8. 效能

每個決定要試跑幾十到一百多個候選（國家最多，約 130 個）。每次試跑複製一份遊戲狀態（約 25 KB、0.2 ms）並套用命令，只取精簡視圖（約 0.3 ms）算指標，不取完整的 `playerView`（約 3 ms）。實測四個目標導向 AI 打完一整局約 5 秒，平均每個決定約 50 毫秒。

## 9. 強度（24 局同種子配對，其餘席位為 `basic`）

| 席位 | `goal-balanced` 比 `basic` 平均多 |
|---|---|
| 勞工 | 15.2 分（標準誤 1.3） |
| 中產 | 19.9 分（標準誤 1.4） |
| 資本家 | 23.0 分（標準誤 3.3） |
| 國家 | 3.8 分（標準誤 0.6） |

各風格的行為差異（資本家席位，12 局平均）：

| 風格 | 建造 | 終局貸款 |
|---|---|---|
| 擴張 | 6.0 次 | 1.3 筆 |
| 均衡 | 4.6 次 | 0.7 筆 |
| 保守 | 4.1 次 | 0.1 筆 |
| 政治 | 2.7 次 | 0.5 筆 |

中產席位的政治風格提案 13.7 次（其他風格約 8 次），總分明顯較低（少 5.6 分）。

## 10. 已知限制

- **只看行動的直接效果**：沒有往後模擬幾個回合，也沒有預測對手的反應。例如調高售價會讓「預期收入」上升，但不會考慮買家買不起；調低薪資會讓「預期支出」下降，不會考慮工人罷工。
- **出牌的參數有限**：非國家席位的手牌只試「不帶參數」與「帶數量 1」兩種形狀，需要指定工人、企業等複雜參數的牌效（例如專業化、合作農場）不會被打出，這些牌只會被當作基本行動的棄牌。
- **特殊階段使用共用預設**：食物、表決、政策調整、市場更新等沿用 `phases.mjs`，不依目標調整（表決一律自己的法案贊成、別人的反對，影響力投入 0）。
- **指標是靜態估計**：收入與支出以目前的價格與薪資級距計算；生產、稅款、貸款利息的實際結算在輪末。
- **確定性**：同樣的盤面一定做同樣的決定（分數相同時依候選順序），沒有隨機成分；AI 之間的節奏差異來自[思考時間](README.md#思考時間)的隨機等待，不影響決策。

## 11. 驗證

```bash
node scripts/bot-arena.mjs --compare working=goal-balanced,basic --games 24 --seats working=basic,middle=basic,capitalist=basic,state=basic
node --test tests/goals.test.mjs
```

`tests/goals.test.mjs` 涵蓋：風格已登錄、指標方向、不同風格對同一盤面排出不同的計畫、四個目標導向 AI 能打完一整局且各席位都留有計畫、只改參數就改變行為（只看法案的風格比只看生產的風格提案更多）。
