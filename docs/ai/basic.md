# 基礎（`basic`）

[最小合法](minimal.md) 加上兩個免費行動：領取福利、有錢就還貸。主要行動與其他階段完全相同。

## 行為

每個回合，主要行動做完後（或之前）如果本回合還沒用免費行動，依序嘗試：

1. `benefits`：領取國家福利（有福利才合法）。
2. `repay`：償還一筆貸款（有貸款且付得起才合法）。

取第一個合法的；都不合法就不做。

## 強度

同種子配對對戰（60 局）：勞工用 basic 比 minimal 平均多 13.6 分（標準誤 0.7），中產多 1.4 分（標準誤 0.14）。

勞工進步大的原因：不再把福利放著不領，貸款也會還，終局貸款扣分從 16.9 降到 4.0。
