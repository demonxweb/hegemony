# 最小合法（`minimal`）

只求「不犯規、不卡住、能把一局打完」，不追求打得好。是所有其他模式的下限，也是測試用的基準。

## 行為

| 情境 | 做法 |
|---|---|
| 勞工、中產、資本家的主要行動 | 一律「施加政治壓力」（棄一張手牌，投票袋加方塊）。這個行動永遠合法 |
| 國家的主要行動 | 依序嘗試：處理事件、公共媒體轉換影響力、提案、會見議員、對外出口、打出手牌（含各種參數形狀）、額外稅；取第一個合法的。都沒有時 `pass` |
| 免費行動 | 不做 |
| 食物結算 | 向比進口便宜的本國賣家買到足夠，不足部分進口；買不起就接受借貸 |
| 表決 | 自己的法案投贊成，其他一律反對；影響力投入 0 |
| 其他階段 | 使用 `phases.mjs` 的共用預設（生產確認、政策調整、市場更新、事件選擇…） |

## 演算法

沒有評分。`turn(ctx)` 回傳一個候選清單，runner 取第一個通過試跑（含後續強制選擇）的。國家的候選清單來自 `packages/engine/candidates.mjs` 的 `stateMainCandidates`，順序刻意把會消耗合法性的額外稅放最後，避免把自己逼進沒有行動可做的盤面。

## 強度

平均總分（60 局，全部席位為 minimal）：勞工 -15.6、中產 6.8、資本家 27.9、國家 37.5。勞工因為不去工作、一直借貸，終局貸款扣分平均 16.9。
